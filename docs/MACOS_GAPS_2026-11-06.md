## 已补齐并验证

- macOS Flutter 宿主、CocoaPods 和原生串口/文件插件；安装 Xcode 16.2 并完成首次启动。
- Release 通用应用：5 个 Mach-O 全部通过 arm64/x86_64 校验及本地签名验证。0.16.9 DMG 已生成，应用已安装到 Applications。
- Command 地图快捷键适配（组件测试通过）；900×650 最小内容窗口及首次尺寸。
- macOS GitHub DMG 元数据识别、下载验证、只读挂载、应用标识/版本/签名/架构验证、暂存、退出交接及失败回退。真实 Flutter DMG 暂存成功，在线完整升级尚未验收。
- 3 个原生功能集成文件通过；手工验证演示轮询中写入、筛选、趋势、原生 CSV 导出、保存重启和串口枚举。
