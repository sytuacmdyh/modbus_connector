# v0.14.2 · 云端同步与调试体验改进

本仓库首个公开发布版本，提供 Windows、macOS、Linux 桌面程序，以及独立 CLI 与 MCP 服务。

## 版本要点

- **云端同步与历史版本**：区分使用者和发布者，可下载公共模板、备份与恢复配置，查看历史版本。
- **手动检查更新**：在 **帮助 → 检查更新…** 中查看本仓库的最新正式版本和下载入口。
- **调试体验改进**：无符号 16 位格式显示为 `u16`，改进停止轮询时的请求取消和错误提示翻译。
- **通信与大表优化**：改善 Windows USB-RS485 分包接收和大型寄存器模板加载、轮询体验。

## 使用说明

启动后可选择 Master、Slave、Sniffer 或 Gateway 模式，连接设备前先核对通信参数。已有配置保存在用户目录的 `.modbus_connector` 中，替换应用目录时请保留该配置文件夹。
