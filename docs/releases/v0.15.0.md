# v0.15.0 · 自定义模板与历史版本

将公共设备模板另存为自己的模板，每次保存自动保留一个历史版本，便于反复调试和找回旧配置。

## 本次更新

- **公共与个人模板分开**：内置和云端同步的模板归入“公共模板”；修改后只能另存为自定义模板，不覆盖公共模板。
- **每次保存保留版本**：按保存时间记录快照，可查看、打开和删除历史版本。
- **管理个人模板**：支持重命名、删除模板；关闭并重新打开程序后，仍可继续保存到原自定义模板。
- **主站与模拟器共用模板入口**：两处菜单都区分公共和自定义模板，保存的模拟器模板可恢复其寄存器映射和规则。

## 如何使用

1. 打开公共模板或编辑当前会话，选择 **模板 → 另存为自定义模板…**。
2. 后续修改后选择 **模板 → 保存新版本**。
3. 在 **模板 → 管理自定义模板…** 中查看历史、打开旧版本，或重命名、删除模板。

打开旧版本后再保存，会新增快照；删除最新版本后，前一版本成为当前版本。最后一个版本需通过“删除模板”一并移除。

## 升级说明

- 从 v0.14.2 升级可沿用现有会话配置，无需手动转换。
- 自定义模板保存在用户目录的 `.modbus_connector/custom_templates/`，与安装目录和公共模板缓存分开存储。
- 云端模板更新不会覆盖自定义模板；公共模板发布也不会上传个人模板。
- 更新前退出程序，替换完整应用目录；保留用户目录下的 `.modbus_connector` 配置文件夹。
